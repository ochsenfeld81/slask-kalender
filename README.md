# Śląsk Wrocław Frauen – Kalender-Abo

Spielplan der Frauen von Śląsk Wrocław (Orlen Ekstraliga) als iCalendar-Datei, alle 4 Stunden neu
aus 90minut.pl gelesen.

Abo-Adresse: https://raw.githubusercontent.com/ochsenfeld81/slask-kalender/main/slask.ics

Regeln stehen oben in `slask.mjs`; Tests: `node --test`.
